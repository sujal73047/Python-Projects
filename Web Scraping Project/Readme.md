# 🌐 Web Scraping & Data Analysis Project

## 📌 Overview
This project focuses on extracting real-world data from a website using web scraping techniques and performing data analysis using Python.

The data was scraped from Wikipedia (List of largest companies in the United States by revenue) and transformed into a structured dataset for further analysis.

---

## 🚀 Features
- Extracts data from a live website using web scraping
- Parses HTML content to collect tabular data
- Cleans and processes raw data
- Converts data into structured format (CSV)
- Performs basic data analysis

---

## 🛠️ Tech Stack
- Python 🐍
- BeautifulSoup
- Requests
- Pandas

---

## ⚙️ How It Works
1. Sends a request to the website using Requests
2. Parses HTML using BeautifulSoup
3. Extracts data from tables
4. Converts extracted data into Pandas DataFrame
5. Cleans and processes the dataset
6. Saves the final data into CSV format

---

## 📊 Output
- A structured dataset in CSV format
- Cleaned and ready for analysis
